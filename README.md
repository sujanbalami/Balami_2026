# SOIL FUNGAL COMMUNITY DYNAMICS AND FUNCTIONAL RECOVERY DURING ECOSYSTEM RESTORATION

**Author:** Sujan Balami

## Overview
This repository contains data, analyses, and supporting materials related to the study of soil fungal community dynamics and functional recovery during ecosystem restoration. The work integrates global meta-analysis with field-based investigations in restored tropical forests, with a particular focus on rubber (*Hevea brasiliensis*) monoculture landscapes.

The project aims to improve understanding of belowground biodiversity recovery—especially soil fungi and arbuscular mycorrhizal (AM) fungi—and their role in ecosystem functioning during restoration.
